# 成员 4 · 官网公开商品联调证据

> 对应契约《接口契约与联调标准.md》第 6 节「官网商品 · 成员 4」：
> 删除匿名 `dealerPrice` 类型，接公开 DTO，加载/空/错误状态。

## 1. 摘要

官网前端（`feature/storefront-products`）已完全切换到公开商品 DTO（`Product` / `ProductDetail` / `ProductVariant`）：

- 前端类型不再存在公开端的 `dealerPrice` / `status` / `stock`；变体只暴露 `isPurchasable`。
- 商品列表页 `GET /products` 与详情页 `GET /products/:slug` 只调用公开 API，不传 `status` 查询参数。
- 加载（`loading.tsx`）、空（`empty-state`）、错误（`error.tsx` / `not-found.tsx`）与移动端适配（`@media`）状态保留。

### 4.3 公开接口拒绝 `status` 查询参数

`GET /products?status=ACTIVE` → `HTTP 400`（契约 §3 禁止公开接口接受状态筛选）：

```json
{
  "success": false,
  "message": ["property status should not exist"]
}
```

## 5. 前端类型变更

`frontend/src/lib/api/types.ts` 公开商品部分（成员 2 契约，PR #5）：

- `Product`：仅公开字段，无 `dealerPrice` / `status`。
- `ProductVariant`：`isPurchasable: boolean`，无 `stock` / `reserved` / 内部状态。
- `ProductListQuery`：`page / limit / sort / categoryId / search`，无 `status`。
- `AdminProduct` / `DealerProduct` 等后台类型保持不变，只供 `/admin/*`、`/dealer/*` 使用。

详情页 `frontend/src/app/products/[slug]/page.tsx` 变体库存显示改为：

```tsx
<span className="variant-list__availability">
  {variant.isPurchasable ? "In stock" : "Out of stock"}
</span>
```

不再读取 `variant.stock`。

## 6. 受影响契约小节

- §2.2 成功/失败响应：维持标准 `{ success, data, message, request_id }` 信封，无变更。
- §3 公开商品：满足「公开商品禁止出现 `dealerPrice`/`status`/`deletedAt`/`createdBy`/内部库存/`reserved`」，且公开接口不接受 `status` 查询（400）。
- §6 官网商品（成员 4）：交付物已达成。

## 7. 结论

官网公开商品列表与详情已只依赖公开 DTO，加载/空/错误/移动端适配状态保留，真实接口联调 7/7 冒烟通过，公开响应不含任何敏感字段。可合入 `develop`。
