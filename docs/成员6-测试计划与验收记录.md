## 5. 自动化结果

执行命令：

```powershell
$env:E2E_BASE_URL="http://localhost:3100/api/v1"
node --test tests/api-smoke.test.mjs
```

2026-09-05 在前一合并 ZIP 基线上实测：6 个测试组通过，0 失败，耗时约 1.77 秒。覆盖健康、Swagger、商品、认证、401/403、空购物车、空购物车下单、经销商审批与企业隔离。最新 `57ab810` 的 Prisma 校验、单元测试、前端 lint 和前后端构建均已复跑通过；后端代码规则在忽略 Windows CRLF/LF 差异后通过。跨模块 API 测试仍需等待 Docker 锁文件在电脑重启后解除，或由本次新增的 GitHub CI 作最终验证。

测试会在 `wemove_test` 中创建带时间戳的临时用户、购物车、经销商申请和企业记录，不得把它指向开发、演示或生产数据库。

## 6. 当前结论

当前 `develop` 已提供 SKU 查询和库存检查服务，但购物车没有注入该服务，种子数据也没有 Variant，因此尚不能判定完整购物链路通过，也不应进入最终发布状态。订单快照仍为占位实现，前端业务页面尚未完成真实联调。
